# OutstandingBlock

What is owed, gross of tax, from any date. `awaitingPayment` and `paymentFailed` add up to it, in count and amount. `overdue` is a part of `awaitingPayment`.

## Example Usage

```typescript
import { OutstandingBlock } from "@paygentic/sdk/models";

let value: OutstandingBlock = {
  count: 312281,
  amount: "831.31",
  awaitingPayment: {
    count: 336537,
    amount: "852.12",
  },
  paymentFailed: {
    count: 402102,
    amount: "380.99",
  },
  overdue: {
    count: 773117,
    amount: "347.70",
  },
};
```

# SubscriptionCreateAddPriceOp

A catalog price the plan version does not carry. The rate is always stored on the interval, because an added price has no plan slot and so version copy-on-write never freezes a snapshot for it. Omit unitPrice to store the named price's own rate; supply one to store a negotiated rate instead. Supply total and installments instead to collect one obligation over several billing periods.

## Example Usage

```typescript
import { SubscriptionCreateAddPriceOp } from "@paygentic/sdk/models";

let value: SubscriptionCreateAddPriceOp = {
  priceId: "<id>",
};
```

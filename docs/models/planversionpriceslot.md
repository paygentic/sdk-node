# PlanVersionPriceSlot

One price slot on a plan version. Every `Price` field is present, plus `priceDeleted` layered on top.

## Example Usage

```typescript
import { PlanVersionPriceSlot } from "@paygentic/sdk/models";

let value: PlanVersionPriceSlot = {
  id: "<id>",
  merchantId: "<id>",
  createdAt: new Date("2024-03-15T08:04:33.038Z"),
  invoiceDisplayName: "<value>",
  model: "standard",
  paymentTerm: "in_arrears",
  properties: {},
  updatedAt: new Date("2026-07-18T12:58:21.852Z"),
  priceDeleted: true,
};
```

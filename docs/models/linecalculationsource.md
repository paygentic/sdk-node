# LineCalculationSource

Where a value came from: `ref`, a link that can break after the invoice is issued, and `asUsed`, the values the calculation read, which never change.

## Example Usage

```typescript
import { LineCalculationSource } from "@paygentic/sdk/models";

let value: LineCalculationSource = {
  type: "<value>",
};
```

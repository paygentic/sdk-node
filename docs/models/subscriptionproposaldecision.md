# SubscriptionProposalDecision

A decision on a pending proposal, and the `hash` of the proposal the person decided on. To reject, send `reason`, and `text` when the reason is `other`. An approval sends neither.

## Example Usage

```typescript
import { SubscriptionProposalDecision } from "@paygentic/sdk/models";

let value: SubscriptionProposalDecision = {
  decision: "approve",
  basedOnHash: "<value>",
};
```

# MintPlanLineInput

One line of the new version: the price it bills, and the key that names it.

## Example Usage

```typescript
import { MintPlanLineInput } from "@paygentic/sdk/models";

let value: MintPlanLineInput = {
  priceId: "<id>",
};
```

# CreditPoolLedgerEntry

A single, typed event in a pool's balance history.

## Example Usage

```typescript
import { CreditPoolLedgerEntry } from "@paygentic/sdk/models";

let value: CreditPoolLedgerEntry = {
  id: "<id>",
  entryType: "void",
  ledgerSequenceNumber: 440726,
  at: new Date("2024-03-01T16:02:41.382Z"),
  amount: 5471.65,
  startingBalance: 6777.72,
  endingBalance: 4147.92,
  grant: {
    id: "<id>",
    expiresAt: new Date("2026-06-11T00:53:09.230Z"),
    conversionRate: "<value>",
  },
};
```

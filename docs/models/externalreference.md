# ExternalReference

Links a Paygentic entity to a record in an external system such as Salesforce or NetSuite.

## Example Usage

```typescript

let value: ExternalReference = {
  id: "<id>",
  merchantId: "<id>",
  entityType: "item",
  entityId: "<id>",
  provider: "<value>",
  externalId: "<id>",
  metadata: {
    "key": "<value>",
  },
  isPrimary: false,
  isDefault: true,
  createdAt: new Date("2025-08-29T06:45:51.723Z"),
  updatedAt: new Date("2026-12-07T18:25:19.013Z"),
};
```

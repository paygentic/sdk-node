# LineCalculationStep

One step: the value it changed (`on`), the value before (`in`) and after (`out`), the rule's parameters, and the source of the rule. A reader that does not know an op shows it as "in → out, because source".

## Example Usage

```typescript
import { LineCalculationStep } from "@paygentic/sdk/models";

let value: LineCalculationStep = {
  op: "<value>",
  on: "<value>",
  in: {
    model: "Altima",
  },
  out: "<value>",
  params: {
    "key": "<value>",
    "key1": "<value>",
    "key2": "<value>",
  },
  source: "<value>",
};
```

# PlanLineInput

One line of a plan: the price it bills, and the key that names it.

## Example Usage

```typescript
import { PlanLineInput } from "@paygentic/sdk/models";

let value: PlanLineInput = {
  priceId: "<id>",
};
```

It starts with a lowercase letter or a digit, contains only lowercase letters, digits, hyphens and underscores, and is at most 64 characters. A key names one line for the life of the plan: every version that keeps the line carries the same key, and a key that you drop from one version and supply again on a later version says that the line resumed. Keys are compared exactly, so `Platform_Fee` is not accepted. |
